# Conti di Casa: regole aggiornate

Valori normativi pubblici (con le fonti) usati dall'app Conti di Casa, firmati con Ed25519.
Nessun dato personale.

## Moduli (formato 1)
`officina/indice.json` (firmato in `officina/indice.json.firma`) elenca i moduli in `officina/moduli/`: valori
nazionali, per regione e per i comuni di ogni regione, ciascuno con la sua impronta sha256. Ogni valore ha fonte,
documento e data di verifica, ed è stato approvato a mano prima della pubblicazione.
